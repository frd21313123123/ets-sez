# Сезоны для ETS 2 (прототип)

Работает только с базовой картой и DLC. Сторонние карты не поддерживаются: мод заменяет сами файлы секторов.

## Запуск

Откройте `launcher.bat`. В окне можно:

- выбрать дату: «Как сегодня» берёт системную дату при каждом запуске, «Своя дата» играет выбранный день;
- посмотреть на карте, где на эту дату лежит снег;
- выбрать профиль и нажать «Играть».

При нажатии лаунчер собирает данные на дату, копирует оба мода в папку игры, ставит их на самый верх списка в профиле и запускает игру через Steam. В игре остаётся выбрать этот профиль.

Если профиля «Сезоны» ещё нет, лаунчер создаст его, а дальше будет менять только список модов в существующем профиле, сохраняя прогресс. Если порядок уже правильный, файл профиля не трогается. Перед изменением рядом сохраняется копия `profile.sii.seasons_bak`.

Игра шифрует профиль при каждом сохранении. Лаунчер умеет его читать, а изменённый записывает обычным текстом: игра его загружает и при следующем сохранении шифрует снова. Поддерживаются только локальные профили, облачными профилями Steam лаунчер не занимается.

Если игра обновилась, лаунчер предложит пересобрать карту. Для этого нужна папка `build\extracted`: её создаёт `tools\extract_textures.bat`.

## Что уже есть

- Дата: длина дня и переход на летнее время.
- Температура и снегопад по секторам карты, плавно по широте и долготе.
- Снег на земле с четырьмя уровнями покрытия. Края размываются смешиванием кусков земли внутри сектора.
- Снег на дорогах и перекрёстках, включая грунтовые и гравийные участки, в разрешении самих дорожных текстур. Разметка остаётся видна, а трещины и пятна уходят под снег.
- Колея: по две полосы от колёс на каждую полосу движения. Положение берётся из геометрии дороги, поэтому колея лежит там, где ездят машины. Под глубоким снегом она остаётся видна как тёмный укатанный след.
- Снег на обочинах, бордюрах, тротуарах и углах перекрёстков: у них свои модели, поэтому они копируются по зонам отдельно.
- Снег на деревьях, кустах, камнях, скалах и дальних горах. Форма листвы не меняется. Лёгкий первый уровень снега деревья не трогает, а кора почти не белеет.

Пока нет: снега на зданиях, осенних листьев и весенней грязи.

Снег получают все материалы земли, кроме воды и невидимых служебных поверхностей. Сократить их число можно через `--top`.

Шесть гаражей и несколько портальных префабов остаются без снега: игра узнаёт их по имени, поэтому копировать их нельзя.

## Как это устроено

Пять модов, все должны быть включены:

| Мод | Что внутри | Когда меняется |
|---|---|---|
| `Seasons: map data` | Секторы с материалами по зонам, копии дорог и перекрёстков | После обновления игры |
| `Seasons: roads`, `Seasons: roads 2` | Текстуры дорог и тротуаров со снегом | После обновления игры |
| `Seasons: nature` | Текстуры земли и деревьев со снегом, копии деревьев и гор | После обновления игры |
| `Seasons: date` | Дата, климаты, уровень снега для каждой зоны | При каждом запуске |

Текстуры лежат в нескольких архивах, потому что каждый архив должен оставаться меньше 4 ГБ. Второй архив дорог заполняется, только если они не помещаются в первый.

Карта разбита на 28 зон по средней температуре января. На выбранную дату для каждой зоны определяется уровень снега.

Дороги, края дорог, перекрёстки, их углы, деревья и горы игра хранит как общие модели, поэтому для каждой зоны есть своя копия. Их геометрия занимает гигабайты, так что копии делят одну запись архива под разными именами. Обычные архиваторы такой файл открыть не смогут, а игре это не мешает: она ищет файлы только по центральному каталогу. Проверку целостности делает `python -m seasons verify`.

Что менять в секторах, сборщик узнаёт из точной структуры формата 907: файл `.data` разбирается поле за полем и обязан закончиться ровно на метке конца. Если игра сменит формат, сборка остановится с ошибкой, а не испортит карту.

## Команды для разработки

Нужны Python 3.11, `numpy` и `Pillow`.

```bash
python -m seasons map --textures build\extracted
```

```bash
python -m seasons date --date 2027-01-20
```

```bash
python -m seasons verify
```

```bash
python -m seasons preview
```

```bash
python -m unittest discover -s tests -t .
```

## Проверка в игре

1. В `game.log.txt` в папке документов игры не должно быть ошибок про `ets_seasons`, `terrain_mat` или `climate`.
2. Для снегопада нужна плохая погода при минусовой температуре, поэтому для проверки возьмите зимнюю дату и езжайте на север.
